# Projet TaskFlow Engine Abdel & Harini

> **Moteur d'exécution concurrent de tâches & Profiler système en C**

## Objectif du projet : TaskFlow Engine est un moteur d'exécution de tâches en arrière-plan codé en C. Il permet d'exécuter des commandes système de manière concurrente, de gérer la communication inter-processus (IPC), d'assurer la synchronisation via une file de tâches et de profiler avec précision l'utilisation des ressources système (temps CPU, mémoire).
